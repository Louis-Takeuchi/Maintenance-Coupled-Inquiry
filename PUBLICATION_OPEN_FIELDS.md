# Publication fields requiring human confirmation

This repository is a public-release candidate, not a fully licensed or fully
citable archival release. The following fields were absent or explicitly left
open in the source package and have not been invented.

## Author and paper metadata

- Author's confirmed English name and name order
- Affiliation and postal address
- Corresponding-author name and public email address
- ORCID
- Final journal status
- Article DOI, volume, issue, and pages
- Repository archive DOI (for example, Zenodo or OSF)
- Funding statement confirmation
- Conflict-of-interest statement confirmation

## License decisions

- Code: choose MIT or Apache-2.0, then install the exact official text
- Data: choose CC0 1.0 or CC BY 4.0, then install the exact official text
- Manuscript, documentation, and figures: confirm CC BY 4.0, then install the
  exact official text

Because the author identity and licenses are unresolved, `CITATION.cff` omits
`authors`, `license`, DOI, and preferred-citation author fields. It is a draft
and should be completed and validated before release publication.
