# Publication metadata for future updates

Version 1.0.0 is licensed and has a valid minimum citation record. The author is
recorded in `CITATION.cff` using the confirmed Unicode name 竹内 琉瑛; an English
transliteration is not inferred.

The following metadata can be added in a later release or at manuscript
submission without delaying this public reproducibility release:

- ORCID
- Affiliation
- Article DOI
- Repository archive DOI (for example, Zenodo or OSF)
- Peer-review and journal-submission information

## Known figure-generation limitation

The supplied public package contains the released PDF and PNG figures, but no
figure-generation source script was found. The existing figures are preserved;
no replacement or inferred generation source has been created.
