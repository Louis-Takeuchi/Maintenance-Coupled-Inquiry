# Known limitations of the public package

1. The prior full raw-trace ZIP failed archive-integrity validation and is excluded.
2. Merged confirmatory data, endpoint analyses, frozen code, manifests, and all execution receipts are included.
3. A fresh raw-step-trace run/deposit is recommended if a venue or reviewer requires every step-level trace.
4. Historical versions are provenance only and must not be pooled with confirmatory evidence.
5. Author identity, license texts, repository DOI, and final publication metadata remain to be filled.
